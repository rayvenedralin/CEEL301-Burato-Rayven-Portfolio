## 📌 Project Overview

This repository hosts the academic and creative portfolio for **CEEL301**, showcasing graphic design, brand identity, digital illustration, publication layouts, and social media campaigns created by **Rayven E. Burato**.

### ✨ Key Features
* **Neo-Brutalist Design System:** High-contrast color palette (Electric Yellow `#FFEA00`, Cyber Cyan `#38BDF8`, Deep Shadow `#1A1A1A`), thick solid borders, retro tactile button states, and badge styling.
* **Interactive Project Filter:** Dynamic tabs allowing instant filtering across categories (All, Illustration/Branding, Social Media, Landing Page, Magazine, Movie Poster, DP Frames).
* **Deep Case Study Modals:** Interactive modal views with client challenge/solution breakdown, typography, color swatches, and deliverables.
* **Certificates Showcase:** Embedded credentials and verifiable certificates (DICT & TESDA) with preview and download actions.
* **Mobile Responsive:** Custom navigation drawer and fluid grid layout optimized for mobile, tablet, and desktop screens.
* **Local Development Server:** Built-in zero-dependency Node.js HTTP server (`server.js`) for rapid local preview and testing.

## 🛠️ Tech Stack

## 🚀 Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/rayvenedralin/CEEL301-Burato-Rayven-Portfolio.git
   cd CEEL301-Burato-Rayven-Portfolio
   ```

2. Start the local server with Node.js:
   ```bash
   node server.js
   ```

3. Open your browser and navigate to:
   ```text
   http://localhost:3000
   ```
